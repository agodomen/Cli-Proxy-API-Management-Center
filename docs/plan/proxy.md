## 代理功能

它的定位是作为一个 “网络代理（Proxy）管理中心”，让用户能够管理自己创建的代理，并查看平台公开可用的代理。通过代理，用户可以为 API 请求配置网络出口，实现特定地域访问、负载均衡或网络加速等目的。

### 一、业务功能

页面主要提供以下核心功能模块：

1. **代理全生命周期管理**
   - **增、删**：支持 **“添加代理”**（通过模态框创建单个或批量代理），并支持对选中的代理进行 **“删除”** 操作。
   - **注意**：从表格操作列来看，**公开代理（Public）不支持编辑和删除**，仅支持“测试连接”和“质量检测”。这表明平台对公开代理采取了“只读”策略，用户只能使用和检测，不能修改或移除。
2. **多维度筛选与检索**
   - **关键词搜索**：通过代理名称进行快速查找。
   - **组合筛选**：提供“代理类型”、“协议”和“状态”三个维度的下拉筛选器，帮助用户快速定位特定类型的代理。
3. **核心资产信息监控**
   - 表格清晰地展示了每个代理的核心信息，包括：**名称**、**可见性**（公开/私有，公开代理还显示创建者信息）、**协议**（HTTP/HTTPS/SOCKS5 等）、**地址**（主机:端口）、**认证方式**（是否需要用户名/密码）、**地理位置**（国旗 + 城市）、**关联账号数**、**网络延迟**（ms）及**质量评级**（如“优质”）、**状态**（正常/异常）。
4. **代理健康与质量检测**
   - **测试连接**：对单个代理发起连通性测试，验证其是否可用。
   - **质量检测**：对单个代理进行更全面的质量评估（可能包括速度、稳定性、匿名性等），并给出质量评分和等级（如“优质”）。
   - **批量质量检测**：支持勾选多个代理，批量触发质量检测任务，提升运维效率。
5. **代理可见性与共享控制**
   - 在创建代理时，可以通过 **“公开给所有用户使用”** 复选框控制代理的可见性。公开代理对所有平台用户可见且可用，私有代理仅创建者本人可见和使用。

### 二、业务流程

该页面支撑了代理从“创建”到“检测”再到“退役”的完整运营流程：

1. **代理创建流程**
   - **入口**：用户点击 **“添加代理”** 按钮，弹出一个模态框。
   - **模式选择**：支持“标准创建”（单个）和“批量创建”（推测为批量导入）两种模式。
   - **配置填写**：填写代理名称、选择协议（HTTP/HTTPS/SOCKS5 等）、输入主机地址和端口，并可选择填写认证信息（用户名/密码）。
   - **高级设置**：配置“到期回退”策略（如“不回退”或“回退到直连”），并决定是否“公开给所有用户使用”。
   - **保存**：点击“创建”，新代理出现在表格中。
2. **代理测试与质量评估流程**
   - **单点测试**：点击代理行中的 **“测试连接”** 按钮，系统发起网络探测，并在按钮上或通过 Toast 提示反馈测试结果（成功/失败及延迟）。
   - **质量检测**：点击 **“质量检测”** 按钮，系统执行更深入的检测（可能包括多地点测速、DNS 解析、匿名性检查等），并在“延迟”列更新延迟数值和质量评级（如“优质”）。
   - **批量检测**：勾选多个代理，点击顶部的 **“批量质量检测”** 按钮，系统为所有选中的代理排队执行质量检测任务。
3. **代理使用与关联流程**
   - **使用**：用户可以在其他模块（如“我的账号”或“我的分组”）中，选择将 API 请求路由到特定的代理上。
   - **关联查看**：在“账号数”列，用户可以看到该代理当前关联了多少个账号，点击可查看具体是哪些账号在使用该代理。
4. **代理退役流程**
   - **选择**：勾选一个或多个代理（私有代理）。
   - **操作**：点击顶部的 **“删除”** 按钮（红色），系统弹出二次确认对话框。
   - **结果**：确认后，代理从系统中移除。**注意：公开代理无法被普通用户删除。**

### 三、交互设计

页面的交互设计围绕 **“网络运维的效率”** 和 **“公开资源的安全性”** 展开，具有以下特点：

1. **布局与视觉反馈**
   - **框架**：沿用“左侧固定侧边栏 + 右侧自适应内容区”的标准后台布局。
   - **主题**：支持深色/浅色模式切换。
   - **数据表格**：表头支持点击排序。左侧（复选框/名称）和右侧（操作按钮）列被设置为**粘性列（Sticky Columns）**，确保在横向滚动时，选择和操作始终可见。
2. **核心交互组件**
   - **高级筛选区**：提供搜索框和“代理类型”、“协议”、“状态”三个筛选器，帮助用户在大量代理中快速定位。
   - **批量操作栏**：顶部提供了 **“测试连接”**、**“批量质量检测”** 和 **“删除”** 三个批量操作按钮。这些按钮在未选中任何代理时处于**禁用状态**，选中后才变为可用，交互反馈清晰。
   - **状态与指标可视化**：“延迟”列使用颜色标签（`badge-success` 绿色表示低延迟，`badge-warning` 橙色表示中等延迟）直观展示网络质量。“账号数”列以可点击的按钮形式呈现，点击可展开查看关联账号详情。
   - **模态框表单**：创建代理使用模态框承载，表单字段按逻辑分组，并提供了“标准/批量”两种创建模式的切换，兼顾了灵活性和效率。
3. **权限与安全设计**
   - **公开代理的保护**：表格中“可见性”为“公开”的代理，其“地址”、“认证”等敏感信息被统一显示为“公开代理隐藏”。这体现了对公开代理提供者的**隐私保护**，防止敏感信息（如服务器 IP、认证凭证）泄露给普通用户。
   - **操作权限控制**：公开代理的操作列仅有“测试连接”和“质量检测”，**没有“编辑”和“删除”按钮**，确保了只有平台管理员才能管理公开资源，保障了共享代理的稳定性。
