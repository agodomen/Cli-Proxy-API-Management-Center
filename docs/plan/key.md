## API密钥

它的定位是作为一个 “API 访问凭证管理中心”，让用户能够创建、管理和监控用于访问平台 API 的密钥（API Key）。通过密钥，用户可以将平台的能力集成到自己的应用或脚本中，并实现精细化的权限和配额控制。

### 一、业务功能

页面主要提供以下核心功能模块：

1. **API 密钥全生命周期管理**
   - **增、删、查**：支持 **“创建密钥”**（通过模态框配置），并在列表中查看所有已创建的密钥。表格中虽然没有直接显示“删除”按钮（因为当前列表为空），但通常此类页面会支持对密钥的 **“删除”** 和 **“撤销”** 操作。
   - **注意**：从表格列设计来看，密钥的 **“API 密钥”** 值在列表中是可见的（但可能有脱敏处理），这表明该平台可能允许用户查看完整的密钥值，或提供了复制功能。
2. **多维度筛选与检索**
   - **关键词搜索**：通过 **“搜索名称或Key”** 进行快速查找。
   - **组合筛选**：提供“分组”和“状态”两个维度的下拉筛选器，帮助用户快速定位特定的密钥。
3. **核心资产信息监控**
   - 表格清晰地展示了每个密钥的核心信息，包括：**名称**、**API 密钥**（实际凭证）、**所属分组**、**当前并发**（正在使用的连接数）、**用量**（已消费的额度）、**过期时间**、**状态**（有效/过期/已撤销）和 **创建时间**。
4. **API 接入端点信息展示**
   - 页面顶部展示了一个特殊的 **“端点列表”**，列出了平台提供的多个 API 接入地址（如 `https://cn.picpi.top`、`https://api.picpi.top` 等）。每个端点都支持 **“复制”** 和 **“测速”** 功能，方便用户选择最优的接入点。
5. **精细化密钥权限与配额控制**（通过创建模态框）
   - **分组关联**：将密钥关联到指定的“分组”，从而继承该分组的所有策略（如费率、限流、模型路由等）。
   - **自定义密钥**：支持用户自定义密钥值（而非系统自动生成），便于与现有系统集成。
   - **IP 限制**：可以限制该密钥仅允许从特定的 IP 地址或 IP 段发起请求，增强安全性。
   - **额度限制**：设置该密钥可消费的最大金额（USD），实现预算控制（0 表示无限制）。
   - **速率限制**：可以设置该密钥的请求频率上限（如每分钟请求数），防止过度使用。
   - **密钥有效期**：可以设置密钥的生效时间段，过期后自动失效。

### 二、业务流程

该页面支撑了 API 密钥从“创建”到“使用”再到“失效”的完整运营流程：

1. **密钥创建流程**
   - **入口**：用户点击 **“创建密钥”** 按钮（页面右上角或空状态引导），弹出一个模态框。
   - **基础配置**：填写密钥名称，并选择关联的 **“分组”**（必选）。选择分组后，密钥将自动继承该分组的所有策略配置。
   - **高级配置**（可选）：根据需要开启 **“自定义密钥”**（输入自己的密钥值）、**“IP 限制”**（添加允许的 IP 列表）、**“额度限制”**（设置最大消费金额）、**“速率限制”**（设置请求频率）和 **“密钥有效期”**（设置生效时间段）。
   - **保存**：点击“创建”，新密钥生成并出现在表格中。如果是系统自动生成密钥，创建成功后通常会**一次性显示完整密钥值**，并提示用户妥善保存（此后不再明文显示）。
2. **端点选择与配置流程**
   - 用户在集成 API 时，需要从页面顶部展示的端点列表中选择一个接入地址。
   - 可以点击 **“测速”** 按钮测试各端点的网络延迟，选择最优的接入点。
   - 点击 **“复制”** 按钮，将端点地址复制到剪贴板，方便粘贴到代码或配置文件中。
3. **密钥使用与监控流程**
   - **集成**：用户将 API 密钥和选定的端点地址配置到自己的应用或脚本中，即可开始调用平台 API。
   - **监控**：在列表中查看密钥的 **“当前并发”** 和 **“用量”**，了解密钥的实时使用情况。如果发现异常高并发或用量突增，可以及时采取措施。
4. **密钥失效与回收流程**
   - **到期失效**：如果密钥设置了“有效期”，到期后自动失效，状态变为“已过期”。
   - **手动撤销**：用户可以通过操作列的 **“删除”** 或 **“撤销”** 按钮手动使密钥失效（通常会触发二次确认），防止被继续使用。

### 三、交互设计

页面的交互设计围绕 **“安全凭证管理”** 和 **“开发者友好”** 展开，具有以下特点：

1. **布局与视觉反馈**
   - **框架**：沿用“左侧固定侧边栏 + 右侧自适应内容区”的标准后台布局。
   - **主题**：支持深色/浅色模式切换。
   - **空状态设计**：当前表格为空时，展示了一个友好的 **“空状态”** 页面，包含图标、提示文案和一个引导性的 **“创建密钥”** 按钮，降低用户的操作门槛。
2. **核心交互组件**
   - **端点信息卡片**：页面顶部以“标签”形式展示了多个 API 端点，每个端点都集成了 **“复制”** 和 **“测速”** 按钮，并带有悬停提示（Tooltip），方便开发者快速选择和使用。
   - **高级配置开关**：创建模态框中，对于“自定义密钥”、“IP 限制”、“速率限制”、“密钥有效期”等高级选项，采用了 **“开关（Toggle）”** 控件，默认关闭，用户按需开启。这实现了“渐进式披露”，降低了表单的复杂度，让基础配置更简洁。
   - **智能默认值**：创建模态框中，分组下拉框默认选中了第一个可用分组（`test121`），减少了用户的操作步骤。
   - **数据脱敏与安全提示**：表格中的“API 密钥”列通常会**部分脱敏**（如只显示前几位和后几位），并在创建成功后强调“请妥善保管此密钥，不再显示”。
3. **数据展示与分页**
   - **表格设计**：表格列包含了密钥管理所需的关键信息，并支持按“状态”、“过期时间”、“创建时间”等列排序。
   - **列设置**：右上角的 **“列设置”** 按钮允许用户自定义表格中显示哪些列，满足不同用户的个性化需求。
   - **状态标识**：“状态”列使用颜色标签（`badge-success`/`badge-warning`/`badge-danger`）直观展示密钥的有效性状态。
