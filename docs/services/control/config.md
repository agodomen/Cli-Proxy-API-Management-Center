# 配置面板

**管理路径：** `/config`

配置面板是管理 CPA 网关基础配置的主入口，提供可视化表单编辑和 YAML 源码编辑双模式，支持变更预览和确认保存。

## 核心功能与服务

1. **双模式编辑**：
   - **可视化编辑（Visual）**：表单字段分组展示，字段验证和类型检查。
   - **源码编辑（Source）**：直接编辑 YAML 配置文件，内置 CodeMirror 编辑器（懒加载）。

2. **配置搜索**：
   - 在配置中搜索关键字，高亮匹配项。
   - 显示当前匹配位置和总数，支持上下导航。

3. **变更对比（Diff）**：
   - 保存前自动对比本地修改与服务器当前配置。
   - 并排 YAML 对比视图，清晰展示新增/修改/删除的字段。

4. **保存与确认**：
   - 未保存变更提醒（dirty state）。
   - 导航离开时确认弹窗，防止误丢失。
   - 支持取消修改回滚到服务器状态。

5. **商业模式识别**：
   - 自动检测 YAML 根节点是否为商业模式，影响部分配置项展示。

## 界面交互与 UI 元素

- **Tab 切换器**：Visual / Source 两个标签页。
- **搜索栏**：输入框 + 当前/总数显示 + 上一个/下一个导航箭头。
- **VisualConfigEditor**：分组折叠的表单区块，每个字段带描述和校验提示。
- **DiffModal**：并排对比弹窗，高亮 diff。
- **操作栏**：保存 / 取消按钮 + dirty 状态指示器。
