# 中心信息

**管理路径：** `/system`

中心信息页面展示管理中心和 CPA 的版本信息、运行状态、模型可用性及全局诊断数据，是系统运维和问题排查的快速入口。

## 核心功能与服务

1. **版本与构建信息**：
   - 管理中心前端版本号。
   - CPA 后端版本号与构建时间。
   - 新版本检测：对比远程最新版本，有更新时显示提示徽章。

2. **模型可用性总览**：
   - 按提供商分类展示可用模型概览（GPT、Claude、Gemini、Kimi 等）。
   - 每个类别显示模型数量和状态指示。

3. **请求日志设置**：
   - 弹窗配置请求日志的启用/禁用开关。
   - 配置日志保留时长、采样率等参数。

4. **缓存管理**：
   - 清除模型缓存。
   - 强制刷新模型列表。

5. **偏好设置**：
   - 主题切换（亮色/暗色）。
   - 语言切换。

6. **外部链接**：
   - 快速跳转到项目文档和 GitHub 仓库。

## 界面交互与 UI 元素

- **版本卡片**：展示当前版本，带更新徽章。
- **模型分类卡片**：按提供商分组的图标 + 模型数量统计。
- **操作按钮组**：检查更新、清除缓存、打开文档。
- **设置弹窗**：请求日志配置模态框。
- **页脚**：构建元数据与环境信息。
