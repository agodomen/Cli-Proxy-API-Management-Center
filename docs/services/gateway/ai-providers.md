# AI 提供商

**管理路径：** `/ai-providers`

AI 提供商是管理中心的核心配置页面，用于统一管理所有上游 AI 模型提供商的连接配置，包括 API 密钥、端点地址、代理、自定义模型映射以及请求头等参数。

## 核心功能与服务

1. **多提供商统一管理**：
   - 支持 **Gemini**、**Codex**、**Claude**、**Vertex**、**OpenAI 兼容服务** 和 **Ampcode** 六类提供商。
   - 每个提供商独立配置，互不干扰。
   - 底部胶囊式导航栏（ProviderNav）快速切换不同提供商。

2. **密钥管理**：
   - 添加/编辑/删除 API 密钥条目。
   - 支持多密钥条目，每个条目可独立指定代理 URL 和认证索引（Auth Index）。
   - 密钥支持显示/隐藏切换（Eye 图标），编辑时保留原密钥（留空则不修改）。
   - 批量操作：测试所选、删除所选、移动密钥到其他提供商。

3. **模型配置**：
   - 自定义模型列表，支持模型名 + 别名（alias）映射。
   - **拉取模型**：一键从提供商的 `/v1/models` 端点获取可用模型列表，通过勾选面板选择并应用到配置。
   - 每个模型可单独配置 **Vision（图片输入）** 支持和 **Thinking 配置**（JSON）。
   - 选择测试模型：可从已配置的模型列表中选取用于连通性测试的模型。

4. **连通性测试**：
   - 单密钥测试：对每条密钥发送最小化聊天请求，实时显示 HTTP 状态码和成功/失败状态。
   - 全部测试：一键测试所有密钥条目。
   - 主面板支持按状态码筛选密钥条目。

5. **数据导入导出**：
   - **导入**：支持粘贴 JSON 或上传 `.json` 文件批量导入密钥。
   - **导出**：将选中的密钥条目导出为标准 JSON 格式。
   - **复制**：一键复制选中的密钥到剪贴板。
   - 导入时自动检测重复密钥，跳过已存在的条目。

6. **同步到词元中心**：
   - 将当前提供商的全部密钥同步到词元中心（公益系统）的密钥库。
   - 支持同步全部提供商或仅同步当前选中的提供商。

## 界面布局

- **左侧边栏**：按 Base URL 分组的提供商列表，支持搜索和启用/禁用筛选，显示每个提供商的密钥数量。
- **右侧主面板**：
  - 顶部：提供商名称、Base URL、启用/禁用开关、删除按钮。
  - 工具栏：搜索、状态码筛选、批量操作按钮（测试所选、移动所选、删除所选、复制、导出、导入、粘贴）。
  - 数据表格：序号、优先级、API 密钥（可脱敏）、代理 URL、测试状态、状态描述、操作按钮。
- **编辑抽屉（Sheet）**：点击"编辑"按钮从右侧滑出，包含基础字段、密钥条目、模型配置、请求头配置等完整表单。
