# OAuth 登录

**管理路径：** `/oauth`

OAuth 登录页面用于发起和管理各 AI 提供商的 OAuth 2.0 授权流程，生成或更新需要用户授权的账号凭证。

## 核心功能与服务

1. **多提供商 OAuth 流程**：
   - **Codex**（OpenAI）
   - **Anthropic**（Claude）
   - **Antigravity**
   - **Kimi**
   - **xAI / Grok**
   - 每个提供商独立卡片，展示品牌图标（支持亮色/暗色主题切换）。

2. **授权流程管理**：
   - 点击"开始授权"后，系统生成授权 URL 并展示。
   - 支持手动输入 / 粘贴授权 URL。
   - 对于支持回调的提供商（Codex、Anthropic、Antigravity、xAI），可粘贴回调 URL 完成授权。
   - 状态追踪：`idle` → `waiting` → `success` / `error`。

3. **Vertex 凭证导入**：
   - 支持从 Google Cloud 的 JSON 服务账号密钥文件导入 Vertex 认证。
   - 导入成功后展示项目 ID、邮箱和区域信息。

4. **凭证落盘**：
   - 授权成功后，凭证自动保存为认证文件，可在「认证文件」页面查看和管理。

## 界面交互与 UI 元素

- **提供商卡片网格**：每个卡片包含品牌图标、名称、状态指示和操作按钮。
- **授权 URL 输入框**：带一键复制功能。
- **回调 URL 输入框**：授权完成后粘贴浏览器跳转回来的完整 URL。
- **文件上传组件**：用于 Vertex JSON 凭证导入。
- **结果弹窗**：展示导入/授权成功后的项目信息。
