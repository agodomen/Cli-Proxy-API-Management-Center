# 运行总览

**管理路径：** `/`

仪表盘是管理中心的运行总览入口，为管理员提供一个集中的监控与控制枢纽，用于实时监控管理中心运行状态、基础连通性指标、常用功能入口及快捷操作。

## 核心功能与服务

1. **实时连接状态指示**：
   - 动态监控管理中心与后端的连接状态。
   - 提取并展示后端服务版本号（Server Version）与构建时间等元数据。
2. **快捷运行统计指标**：
   - **认证文件数量**：实时展示当前系统中已加载和托管的认证文件总数。
   - **AI 提供商状态**：一目了然当前配置的 AI 提供商是否可用。
   - **可用模型状态**：监测全局可用模型的统计信息。
3. **常用操作快速入口**：
   - 针对最常用的业务场景（例如密钥管理、接口调试、系统设置）提供快速跳转通道。

## 界面交互与 UI 元素

- **状态指标卡片（Quick Stat Cards）**：内置图标指示（如 `IconKey`、`IconBot`、`IconFileText`、`IconSatellite` 等），清晰展示各个系统的统计概览。
- **全局连接状态栏**：位于顶部，在加载时显示 Skeleton 骨架屏或 Loading，成功后显示健康的绿标，失败则显示重连提示。
- **模块导航网格**：响应式网格布局，点击可无缝跳转到具体的管理页面。
