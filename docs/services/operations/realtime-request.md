# 实时监控

**管理路径：** `/realtime/request`

实时监控页面通过 SSE（Server-Sent Events）持续展示最新请求记录和请求状态，适用于快速发现接入异常和请求级故障。

## 核心功能与服务

1. **实时日志流**：
   - 通过 SSE 接收变更通知（cursor / 时间戳），再 quiet 拉取当前筛选下的 realtime 分页。
   - 实时页不请求 `/usage/summary`，减少无效负载；高频 SSE 事件会做 300ms 防抖合并。
   - SSE 断开后前端会自动重连；网络恢复或页面重新可见时也会主动尝试连接。

2. **多维过滤**：
   - 按认证文件（auth file）过滤。
   - 按提供商过滤。
   - 按状态码过滤。
   - 全文搜索。

3. **成功率可视化**：
   - 计算并展示最近 N 条请求的成功率。
   - 每行展示成功/失败模式可视化条。

4. **账号导入**：
   - 支持导入 legacy OpenAI 风格用量文件（`AccountImportModal`）。
   - 文件校验和分块上传进度展示。
   - 可在导入前通过滑动开关设置账号默认状态：默认禁用，可切换为启用。

5. **监控开关**：
   - 按认证文件或提供商单独启用/禁用监控。
   - 操作带确认对话框。
   - 禁用状态显示 loading 状态。

6. **分页浏览**：
   - 支持分页和自定义每页条数。
   - 显示当前条目范围（如 1-20 / 共 156 条）。

## 界面交互与 UI 元素

- **过滤栏**：搜索框、提供商下拉、状态开关。
- **日志行组件**：脱敏 API Key、时间戳、状态徽章。
- **成功率迷你图**：每行显示请求成功/失败模式条。
- **账号导入弹窗**：文件选择 + 校验 + 进度条。
- **开关组件**：启用/禁用监控的 ToggleSwitch。
