# 请求监控

**管理路径：** `/monitoring`

请求监控页面是 API 用量分析的核心仪表盘，汇总 API 请求用量、模型、账号、状态和费用等监控指标，由 usage-service 负责采集与查询。

## 核心功能与服务

1. **用量汇总看板**：
   - 按时间范围（预设/自定义）筛选监控数据。
   - 展示总请求数、成功数、失败数、平均延迟等关键指标。
   - 按账号/提供商/模型分组聚合。

2. **API Key 性能明细**：
   - 表格展示每个 API Key 的优先级、状态、请求量。
   - 支持密钥脱敏显示（mask）和明文切换。
   - 按状态码过滤。

3. **实时事件流**：
   - 自动刷新展示最新请求事件。
   - 可配置刷新间隔（5s / 30s / 1m / 5m）。
   - 支持暂停/恢复自动刷新。

4. **健康状态可视化**：
   - 状态指示器（正常/异常/未知）。
   - 支持键盘导航和无障碍访问。

5. **数据导入导出**：
   - 账号数据导入（支持 legacy OpenAI 用量文件格式）。
   - 分页查询，支持自定义每页条数。

## 界面交互与 UI 元素

- **汇总卡片区**：指标数值 + 趋势迷你图（sparklines）。
- **分页表格**：可排序列、行操作按钮、状态筛选芯片。
- **时间范围选择器**：预设快捷选项 + 自定义日期范围。
- **自动刷新开关**：下拉选择间隔时间。
- **MonitoringPanel 折叠组件**：可展开的详情区块。
