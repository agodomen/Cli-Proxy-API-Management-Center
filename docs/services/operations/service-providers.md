# 密钥管理

**管理路径：** `/service-providers`

密钥管理页面用于管理 CPA 侧服务提供商的 API Key 条目，支持连通性测试、模型拉取、密钥同步到词元中心等完整生命周期操作。

## 核心功能与服务

1. **提供商侧边栏**：
   - 左侧按 Base URL 分组列出所有提供商。
   - 支持搜索 Base URL / 提供商名称。
   - 启用 / 禁用 / 全部三种可见性筛选。
   - 显示每个提供商的密钥数量。

2. **密钥条目管理**：
   - 表格展示：优先级、API Key（脱敏）、代理 URL、测试状态、状态描述。
   - 单条测试：对指定密钥发送最小化聊天请求，显示 HTTP 状态码。
   - 批量测试：对选中的多条密钥并行测试。
   - 移动密钥：将密钥从一个提供商移动到另一个（相同 Base URL 下）。
   - 删除密钥（单条 / 批量）。

3. **编辑抽屉（Sheet）**：
   - 点击"编辑"从右侧滑出完整配置面板。
   - 支持添加/删除/测试 API Key 条目。
   - 每个条目可配置代理 URL 和 Auth Index。
   - 拉取模型：从 `/v1/models` 端点获取可用模型，通过勾选面板批量添加。
   - 模型配置：别名（alias）、Vision（图片输入）支持、Thinking JSON 配置。
   - 自定义请求头：支持添加/删除 Header，预设 Codex / Claude User-Agent。
   - 测试模型选择：下拉选择用于连通性测试的模型。
   - 全部测试：一键测试抽屉内所有密钥。

4. **导入导出**：
   - JSON 导入：粘贴或上传 `.json` 文件批量导入密钥。
   - JSON 导出：将选中密钥导出为标准格式。
   - 剪贴板导入/导出。
   - 重复密钥自动检测与处理策略（保留重复 / 删除去重 / 覆盖去重）。

5. **同步到词元中心**：
   - 将提供商密钥批量同步到公益系统的密钥库。
   - 支持同步全部提供商或仅同步当前选中提供商。
   - 同步结果展示（同步数 / 跳过数 / 总数）。

## 界面交互与 UI 元素

- **左侧边栏**：提供商列表 + 搜索 + 筛选按钮组 + 密钥计数徽章。
- **右侧主面板**：
  - 顶部：提供商名称、Base URL、启用/禁用开关、删除按钮。
  - 工具栏：搜索、状态码筛选、批量操作按钮（测试所选、移动、删除、复制、导出、导入、粘贴、全部测试）。
  - 数据表格：序号、优先级、API Key、代理 URL、状态码、状态描述、操作列。
- **编辑抽屉**：表单验证、折叠区块、加载状态、错误提示。
- **重复密钥处理弹窗**：三种去重策略供选择。
