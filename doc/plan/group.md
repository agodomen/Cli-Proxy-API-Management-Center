## 分组功能

它的定位是作为一个 “策略与资源分组中心”，让用户能够将分散的 AI 账号按照业务线、平台类型、计费模式或特定用途（如 Claude Code 专用）进行逻辑分组。通过分组，用户可以统一配置费率、限流策略、模型路由和访问控制，从而实现精细化的资源管理和成本控制。

### 一、业务功能

页面主要提供以下核心功能模块：

1. **分组全生命周期管理**
   - **增、删、改、拷**：支持“创建分组”，并对列表中任一分组进行“编辑”、“复制”和“删除”操作。“复制”功能可以基于现有分组快速创建一个配置相同的新分组，大幅提升配置效率。
2. **多维度筛选与检索**
   - **关键词搜索**：通过分组名称进行快速查找。
   - **组合筛选**：提供“平台”和“状态”两个维度的下拉筛选器，帮助用户在海量分组中快速定位目标。
3. **核心资产信息监控**
   - 表格清晰地展示了每个分组的核心信息，包括：**名称**、**平台**（如 Anthropic）、**计费类型**（订阅/标准）、**费率倍数**、**账号数**（可用/总量）、**容量使用情况**、**用量统计**（今日/累计）和 **状态**（正常/异常等）。
4. **精细化策略与路由控制（高级配置）**
   这是该页面的核心价值所在，通过“创建/编辑分组”模态框提供了丰富的策略配置项：
   - **基础费率控制**：设置 **“费率倍数”**，实现对该分组下所有账号的计价调整（如 0.5 倍半价、2.0 倍双倍）。
   - **用户级限流**：设置 **“每分钟请求数 (RPM)”**，可以覆盖用户级别的限流策略，实现更细粒度的流量控制。
   - **计费与配额管理**：选择 **“计费类型”**（标准从余额扣费，或使用订阅配额），并可设置 **每日/每周/每月** 的消费限额（USD），防止预算超支。
   - **模型可见性控制**：通过 **“自定义 /v1/models 模型列表”** 开关，控制该分组下的用户通过 API 查询模型列表时能看到哪些模型（仅影响展示，不影响实际调用）。
   - **客户端访问限制**：通过 **“Claude Code 客户端限制”** 开关，可以将该分组设置为仅允许 Claude Code 官方客户端访问，实现特定工具的专用资源池。
   - **账号来源过滤**：通过 **“仅允许 OAuth 账号”** 和 **“仅允许隐私保护已设置的账号”** 开关，自动过滤不符合条件的账号，确保分组内的账号符合安全和合规要求。
   - **模型路由配置**：通过 **“模型路由配置”** 开关，可以启用高级路由规则，将特定模型（支持通配符匹配，如 `claude-opus-*`）的请求优先路由到本分组的账号。

### 二、业务流程

该页面支撑了分组从“创建”到“应用”再到“退役”的完整运营流程：

1. **分组创建流程**
   - **入口**：用户点击 **“创建分组”** 按钮，弹出一个内容丰富的模态框。
   - **基础配置**：填写分组名称、描述，并选择关联的平台（如 OpenAI / Anthropic）。
   - **策略配置**：设置费率倍数、RPM 限制、计费类型及配额。
   - **高级功能配置**：根据需要开启“Claude Code 限制”、“账号过滤”或“模型路由”等高级开关并设置具体规则。
   - **保存**：点击“创建”，新分组出现在表格中。
2. **分组编辑与复制流程**
   - **编辑**：点击表格行中的 **“编辑”** 按钮，弹出与创建相同的模态框并回填现有数据，修改后保存即可。
   - **复制**：点击 **“复制”** 按钮，系统会基于当前分组的配置创建一个新分组（通常名称会带有 `-copy` 后缀），用户只需微调名称等关键信息即可快速上线。
3. **分组删除流程**
   - **操作**：点击表格行中的 **“删除”** 按钮，系统会弹出二次确认对话框，防止误操作。
   - **结果**：确认后，该分组及其关联的配置策略从系统中移除。
4. **账号关联与策略应用流程**
   - **关联**：创建分组后，用户需要前往 **“我的账号”** 页面，将具体的 API 账号分配到该分组下。
   - **生效**：账号被分配到分组后，该分组的所有策略（费率、限流、路由等）会自动应用到这些账号上，实现对 API 调用的统一管控。

### 三、交互设计

页面的交互设计围绕 **“高效配置”** 和 **“复杂策略的清晰呈现”** 展开，具有以下特点：

1. **布局与视觉反馈**
   - **框架**：沿用“左侧固定侧边栏 + 右侧自适应内容区”的标准后台布局。
   - **主题**：支持深色/浅色模式切换。
   - **数据表格**：表头支持点击排序。操作列（编辑/复制/删除）被设置为**粘性列（Sticky Columns）**，确保在横向滚动时关键操作始终可见。
2. **核心交互组件**
   - **高级筛选区**：提供搜索框和“平台”、“状态”两个筛选器，帮助用户在众多分组中快速定位。
   - **复杂表单（模态框）**：创建/编辑分组使用模态框承载，表单内容按逻辑分为**基础设置、计费与配额、高级特性**等多个区域。大量使用**开关（Toggle）** 来控制高级功能的启用/禁用，实现了“渐进式披露”，默认折叠复杂选项，降低用户认知负担。
   - **内联操作**：表格行内直接提供“编辑”、“复制”、“删除”按钮，操作路径极短。
   - **帮助提示（Tooltip）**：针对“Claude Code 客户端限制”和“模型路由配置”等复杂或专业概念，旁边放置了带问号的图标，悬停时弹出详细解释，降低了用户的学习成本。
3. **数据展示与分页**
   - **统计信息**：表格底部清晰显示当前分组的数量统计（如“共 1 条结果”）。
   - **自定义分页**：支持自定义每页显示条数，并提供完整的页码跳转控件，确保在处理大量分组数据时的良好体验。
