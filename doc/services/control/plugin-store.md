# 插件商店

**管理路径：** `/plugin-store`

插件商店提供插件市场浏览、安装和更新功能。该菜单仅在当前 CPA 能力支持插件时显示。

## 核心功能与服务

1. **插件浏览**：
   - 分类展示官方和社区插件。
   - 插件卡片展示名称、简介、版本、下载量、评分。

2. **插件安装与更新**：
   - 一键安装未安装的插件。
   - 已安装插件显示"更新"按钮（当有新版本时）。
   - 安装进度和状态反馈。
   - 插件安装请求最多等待 10 分钟；浏览器不会按普通管理请求的 30 秒超时提前取消。
   - 二进制下载流被代理临时中断时，后端最多自动重试 2 次；服务退出或安装上下文真正超时后不再重试。

3. **插件详情**：
   - 查看插件完整描述、作者、依赖项、兼容版本。
   - 用户评价和安装统计。

## 界面交互与 UI 元素

- **插件卡片网格**：图标、名称、简介、安装按钮。
- **安装状态指示**：安装中（进度条）/ 已安装 / 可更新。
- **搜索与筛选**：按分类或关键字搜索插件。

> 插件商店的具体实现可能依赖外部插件注册中心 API，如有变动请以实际页面为准。

## 显示条件

与「插件管理」相同：仅当运行中的 CPA/cpamc 二进制以 CGO 构建并返回 `X-CPA-SUPPORT-PLUGIN: 1` 时，侧边栏与路由才会开放 `/plugin-store`。

## 代理与下载

- 插件商店列表/安装共用后端出站网络配置：`plugin-proxy` 的 status 决定直连、系统代理、自定义代理或 GitHub 加速器。
- GitHub Release 资源下载常会 302 到带临时 `token` 查询参数的 CDN 地址；运行时请求允许跟随该签名链接。
- 加速器只改写可下载的 GitHub 资源（`github.com` releases、`raw.githubusercontent.com`、CDN 等），**不会**改写 `api.github.com` 元数据请求，避免公共加速器共享出口 IP 触发 GitHub REST 限流 403。
- 注册表/清单中声明的永久 artifact URL 仍禁止携带 `token`/`api_key` 等敏感 query，避免把长期密钥写进配置。
