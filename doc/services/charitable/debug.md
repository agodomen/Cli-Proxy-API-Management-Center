# 调试开发

**管理路径：** `/charitable/debug`

调试开发是公益功能下的统一调试工作台，集成 SQL 调试、API 调试和密钥调试三大子功能，为后端数据库查询、接口验证和凭证提取提供一站式工具。

## SQL 调试

- 连接并查询后台业务 SQLite 数据库。
- 支持多数据库切换（主库、用量库、日志库）。
- 表结构浏览器：展开表/视图，查看列元数据。
- SQL 编辑器：语法高亮、格式化、模板片段快速插入。
- 查询执行：展示结果表格、行数、执行耗时。
- 受确认保护的写操作：INSERT / UPDATE / DELETE 前弹出确认弹窗，预览受影响行。
- 结果导出：CSV 下载、复制到剪贴板。
- 统计模板：预置常用诊断查询（`StatsTemplates`）。

## API 调试

- 构造并验证公益管理 REST 接口。
- 支持选择接口模板（GET/POST/PUT/DELETE）。
- 设置路径参数、Query 参数与请求体。
- 查看响应状态码、响应头和响应内容。

## 密钥调试

从用户粘贴的文本中识别密钥配置，通过 LLM 提取或人工填写的方式还原 Base URL / API Key / Model，完成探测后可导入词元中心。

1. **LLM 自动提取**：
   - 使用系统配置的提取模型（或自动路由）对文本进行智能解析。
   - 自定义系统提示词（System Prompt），可保存多套提示词配置。
   - 提取结果展示为候选卡片，点击即可应用。

2. **手动填写**：
   - LLM 提取失败或不可用时，降级为手动填写表单。
   - 填写 Base URL、API Key、可选 Model。

3. **协议探测（Probe）**：
   - 对提取或填写的密钥执行 OpenAI 协议连通性测试。
   - 测试模型可指定，支持探测多个模型。
   - 实时展示探测结果：状态码、成功/失败指示、错误信息。

4. **保存到词元中心**：
   - 探测成功的密钥可一键保存到词元中心的提供商配置中。
   - 自动生成提供商名称和认证索引。

## 界面交互与 UI 元素

- **工作台 Tab 切换**：SQL 调试 / API 调试 / 密钥调试。
- **SchemaBrowser**：可展开的表/视图树形浏览器。
- **SqlEditor**：带工具栏的 SQL 编辑器（格式化、执行、清空、模板）。
- **ResultTable**：可排序的结果表格 + 分页。
- **WriteConfirmModal**：写操作确认弹窗，预览受影响行。
- **KeyDebugPanel**：
  - 原始文本输入区 + 提取按钮（提取中显示 Loading 动画）。
  - 提取模型选择下拉（auto / 具体模型）。
  - 探测 Prompt 输入 + 随机数学题生成按钮。
  - 协议选择复选框。
  - 候选结果列表 + 探测结果展示。

## 注意事项

调试操作可能接触数据库、管理密钥和认证凭证，应避免在非受控环境中展示或保存敏感内容。
