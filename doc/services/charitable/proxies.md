# 代理管理

**管理路径：** `/charitable/proxies`

代理管理页面用于管理公益系统使用的代理服务器，支持多种代理协议、连通性测试、批量操作及 Clash Verge 扩展脚本导出。

## 核心功能与服务

1. **代理列表管理**：
   - 展示代理索引、协议类型、地址、状态、优先级。
   - 支持分页和关键字搜索。
   - 按状态 / 代理类型筛选。

2. **代理类型自动检测**：
   - 根据 URI 前缀自动识别协议类型：`vmess://`、`vless://`、`socks5://`、`http://`、`trojan://`、`ss://`、`ssr://`、`hysteria://`、`tuic://`、`naive://`、`juicity://`、`overtls://`、`wireguard://` 等共 17 种。

3. **连通性测试**：
   - 对单个代理执行连通性探测。
   - 站点可达性测试：测试代理对 Google / GitHub 等目标站点的连通情况。
   - 测试结果抽屉展示：站点网格 + 延迟徽章。

4. **批量操作**：
   - 批量删除选中代理。
   - 导出选中代理配置。

5. **Clash Verge 扩展脚本导出**：
   - 根据当前搜索、状态和代理类型筛选条件生成扩展脚本。
   - 优先级 `<0` 的节点归为公共节点，`>=0` 的节点归为私人节点。
   - 支持一键复制完整脚本到剪贴板，或保留为 JavaScript 文件。
   - 复制后提示公共节点、私人节点和无法转换而跳过的数量。

6. **参数编辑器**：
   - 高级代理配置使用可视化 JSON 参数编辑器（ParamEditor）。
   - 支持嵌套结构的键值对编辑。

## 界面交互与 UI 元素

- **数据表格**：代理索引、协议、地址、状态、优先级、操作列。
- **编辑抽屉（Sheet）**：代理类型自动补全下拉 + 值输入 + 协议检测状态。
- **测试结果抽屉（ProxySiteTestDrawer）**：站点网格 + 延迟徽章 + 通过/失败指示。
- **导出下拉菜单**：JSON / Clash 配置 / 复制到剪贴板。
- **状态提示 Tooltip**：探测结果悬停提示。
