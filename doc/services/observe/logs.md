# 日志查看

**管理路径：** `/logs`

日志查看页面用于实时流式展示 CPA 运行日志和请求追踪信息，是定位连接、认证、转发和上游响应问题的核心工具。

## 核心功能与服务

1. **实时日志流**：
   - 增量加载日志，通过重叠检测避免重复条目。
   - 自动滚动开关：开启后始终跟随最新日志，关闭后可手动定位。

2. **高级过滤**：
   - 按 HTTP 方法（GET / POST / PUT / DELETE 等）过滤。
   - 按状态码分组（2xx / 4xx / 5xx）过滤。
   - 按时间范围过滤。
   - 全文搜索：支持正则表达式和通配符。

3. **日志解析与高亮**：
   - JSON 结构自动语法高亮。
   - 错误堆栈追踪高亮显示。
   - 等宽字体 + 行号显示。

4. **导出与错误日志**：
   - 导出当前过滤结果为文本文件。
   - 错误日志文件浏览器弹窗：浏览服务器端错误日志文件并预览内容。

5. **操作控制**：
   - 刷新、清空、导出、切换自动滚动。
   - 搜索结果计数与上下导航。

## 界面交互与 UI 元素

- **过滤工具栏**：方法芯片、状态开关、时间选择器、搜索输入框。
- **日志面板**：等宽字体、行号、语法高亮、可滚动。
- **操作按钮组**：刷新、导出、清空、自动滚动开关。
- **错误日志文件弹窗**：文件列表 + 内容预览。
