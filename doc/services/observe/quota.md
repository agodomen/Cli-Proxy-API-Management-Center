# 配额管理

**管理路径：** `/quota`

配额管理页面按提供商和账号维度展示配额窗口、用量与限额状态，帮助运维人员判断账号调度策略和配额健康度。

## 核心功能与服务

1. **多提供商配额总览**：
   - 覆盖 Claude、Antigravity、Codex、xAI、Kimi 等提供商。
   - 每个提供商独立的 `QuotaSection` 区块，展示该提供商下所有认证文件的配额信息。

2. **配额指标展示**：
   - 剩余配额 / 已用量。
   - 用量百分比进度条。
   - 配额重置时间表。
   - 按认证文件维度分组显示。

3. **数据刷新**：
   - 顶部刷新按钮手动拉取最新配额数据。
   - 未连接状态时，操作按钮自动禁用。

## 界面交互与 UI 元素

- **配额区块（QuotaSection）**：按提供商分组的可复用组件，包含提供商名称、图标和配额列表。
- **进度条 / 数值展示**：直观呈现配额消耗情况。
- **骨架屏与错误提示**：加载中显示骨架屏，失败时显示错误横幅。
- **连接状态门控**：仅在管理中心与 CPA 连接正常时启用操作。
